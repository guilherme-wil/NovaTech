<section class="project-description">
  <h1>NovaTech — Premium Tech Landing Page</h1>

  <p>
    Landing page premium desenvolvida para uma startup fictícia de tecnologia chamada
    <strong>“NovaTech”</strong>.
  </p>

  <p>
    O objetivo do projeto foi criar uma experiência visual moderna e sofisticada
    utilizando <strong>HTML</strong>, <strong>CSS</strong> e
    <strong>JavaScript puro</strong>, com foco em animações suaves,
    performance, responsividade e design profissional.
  </p>

  <p>
    Durante o desenvolvimento, utilizei ferramentas de IA como suporte para
    prototipagem, refinamento da interface e aceleração do processo de
    desenvolvimento front-end.
  </p>

  <h2>✨ Features</h2>

  <ul>
    <li>Design futurista e premium</li>
    <li>Totalmente responsivo</li>
    <li>Dark mode moderno</li>
    <li>Glassmorphism</li>
    <li>Canvas animado</li>
    <li>Scroll reveal animations</li>
    <li>Parallax effects</li>
    <li>Carousel interativo</li>
    <li>Loading screen personalizada</li>
    <li>Cursor customizado</li>
    <li>Microinterações</li>
    <li>Navbar dinâmica</li>
    <li>Hover effects sofisticados</li>
  </ul>

  <h2>🚀 Tecnologias</h2>

  <ul>
    <li>HTML5</li>
    <li>CSS3</li>
    <li>JavaScript Vanilla</li>
  </ul>

  <h2>🎯 Objetivo</h2>

  <p>
    Este projeto foi desenvolvido para demonstrar habilidades em front-end,
    UI/UX e criação de interfaces modernas com aparência de produto real,
    utilizando IA como ferramenta de apoio no processo criativo e de
    desenvolvimento.
  </p>
</section>
